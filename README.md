# Football Match Outcome Prediction System

A final-year BCA project that predicts the outcome of football matches
(Home Win / Draw / Away Win) using Logistic Regression.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Machine Learning:** Scikit-learn (Logistic Regression), Pandas
- **Database:** MySQL

## Project Modules

1. Data Processing
2. Feature Engineering
3. Model Training
4. Model Evaluation
5. Prediction
6. Flask Web Application
7. MySQL Database
8. User Authentication
9. Prediction History
