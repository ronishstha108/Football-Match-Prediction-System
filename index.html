About This Project

This is an academic project developed as part of the Bachelor of Computer Applications (BCA) program at Tribhuvan University, Nepal.

The goal is to build a system that predicts LaLiga football match outcomes using historical match data and a machine learning algorithm called Logistic Regression.

This project is developed in stages. The current stage shows only the landing page. The prediction system, database, and backend will be added in later stages.
